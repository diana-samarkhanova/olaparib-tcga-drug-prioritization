# TCGA and published resistance-context reproduction

These scripts reproduce the targeted TCGA-BRCA analysis and extract published
GSE165914 differential-expression estimates. The repository stores code and
provenance; restore the analysis inputs before running the commands below.

## Environment

Use Python 3.12 and install the archived direct-dependency versions:

```bash
python -m pip install -r analysis/tcga_extended/requirements.txt
```

The list pins pandas 2.2.3, numpy 2.3.5, scipy 1.17.0, lifelines 0.30.3,
matplotlib 3.10.8, and openpyxl 3.1.5. It is not a complete transitive lockfile.

## TCGA inputs

Restore `analysis/tcga_extended/raw/` and its source manifests from the analysis
archive. Required inputs are the clinical patient, primary-sample, and Firehose
receptor-status tables; TCGA-CDR supplemental table; RNA and CNA matrices;
MSigDB Hallmark 2025.1.Hs definitions; RPPA matrix; mutation case list; and the
per-gene mutation JSON snapshots. The compact RNA and CNA inputs in the archive
are accepted when their full matrices are absent. Their hashes are recorded in
`computation_subset_manifest.json`; the RNA subset retains the required genes
for all eleven signatures and the candidate panel.

The archive omits the original `raw/purity.tsv`, although the reported adjusted
pathway analysis used purity for 1,021 of 1,082 matched patients. **Do not omit
purity when reproducing that analysis.** The 20 October 2026 audit recovered the
original GDC file with the exact recorded SHA-256; all matched values and missing
values agreed with the archived intermediate. The corrected QC cohort has purity
for 1,019 of 1,077 RNA-matched patients. If the original source is unavailable,
recover the archived cohort's values from its saved clinical intermediate:

```bash
python analysis/tcga_extended/reconstruct_archived_purity.py
```

This creates `raw/purity_archive_derived.tsv` and an explicit provenance JSON
with source/output hashes. It does not recreate the full original GDC file.
Run it immediately after restoring `matched_clinical_cohort.csv`, before
overwriting that intermediate with a new run. Original `raw/purity.tsv` takes
precedence; the derived fallback prints a warning. Missing or unusable purity
now stops analysis instead of silently changing adjustment covariates.

For source retrieval rather than archive restoration:

```bash
python analysis/tcga_extended/download_sources.py
```

The downloader verifies SHA-256 before replacing local files and stops on a
changed snapshot. It retrieves all used source entries, including the full RNA
and CNA matrices (more than 200 MB combined); it does not need to run for an
offline compact-input rerun. `--include-unused` also retrieves provenance-only
sources. Live URLs are not guaranteed to keep serving the recorded snapshots.

## Run order

Run from the repository root after restoring inputs:

```bash
python analysis/tcga_extended/reconstruct_archived_purity.py
python analysis/tcga_extended/analyze_tcga.py
python analysis/tcga_extended/analyze_mutations_and_sensitivity.py
python analysis/astra_extended/build_synthesis.py
python analysis/astra_extended/analyze_gse165914.py
python analysis/extended_root/plot_project_evidence.py
python analysis/astra_extended/integrate_context.py
```

Skip the first command if using the original purity input. The main TCGA script
creates its tables and figures; mutation analysis adds mutation and PAM50
survival-sensitivity results. The main module is also importable without reading
inputs or creating output directories. Its CLI can keep a verified input snapshot
and a new output directory separate:

```bash
python analysis/tcga_extended/analyze_tcga.py --raw /path/to/verified/raw --root /path/to/new/tcga_run
```

`--figures-dir` selects a separate PNG directory; `--no-figures` skips plotting.
The downstream mutation and report scripts still use their documented project
paths, so the standard run order above is appropriate for a complete project
rebuild. Preserve archived outputs before running into an existing directory.
There is no `--legacy` mode: historical reproduction requires the archived code
and inputs, because reverting only rank or duplicate-row handling would omit
other differences from the current QC policy.

To redraw existing TCGA tables without refitting:

```bash
python analysis/tcga_extended/plot_saved_results.py
python analysis/tcga_extended/plot_mutations_saved.py
```

GSE/context integration additionally requires:

- `analysis/mechanisms_extended/evidence.csv` for the curated synthesis;
- `analysis/astra_extended/raw/GSE165914_M468P_OR_Diff_Expression_mshekhar.csv.gz`;
- `analysis/astra_extended/raw/GSE165914_SUM_M468_Parental_OR_counts_mshekhar.csv.gz`;
- `outputs/TCGA_Drug_Analysis_EN_20261013/tables/Selected_CRISPR_panel_20_genes.csv`
  generated by `plot_project_evidence.py` from the current screen-summary tables.
  That figure script also requires the restored drug-resource results described
  in [the figure commands](CRISPR_REPRODUCIBILITY.md#project-figures).

The restored root `tables/Selected_CRISPR_panel_20_genes.csv` is an archival
snapshot. Context integration deliberately does not fall back to that copy:
otherwise a new screen analysis could be joined to stale screen calls. A missing
generated panel stops with the command needed to create it.

GEO source URLs are recorded in the archived `GSE165914_metadata.txt`.
`build_synthesis.py` writes curated mechanistic interpretation, not a learned
ranking. It overwrites the priority matrix, so rerun extraction and integration
after it to restore the appended contextual columns.

## Expected checks and interpretation

The archived baseline has 1,082 unique RNA-matched primary patients: 157 clinical
TNBC, 848 non-TNBC, and 77 unclassified, with 171 separately classified PAM50
basal tumours. The corrected analysis applies a conservative TCGA-CDR flag-based
QC policy before all molecular and clinical analyses: five cases carrying
`Redaction=Redacted` are excluded. The resulting cohort has **1,077** RNA-matched
patients: **156 TNBC, 844 non-TNBC, and 77 unclassified**, with **170 PAM50 basal**
tumours. Historical flags can describe corrected aliquot problems; they do not
mean that all five patients withdrew consent or that every later aliquot is
invalid. The sample-level matrix does not establish the replacement aliquot
identity, so exclusion is a declared conservative decision. The baseline is
retained for the before/after comparison. Only aggregate exclusion counts are
reported in `cohort_counts.json`; excluded identifiers are not added to outputs.

Nineteen coding candidates are represented; LINC03007 is absent from the
selected RNA/CNA platform. LAMTOR2 uses the source alias ROBLD3. The source RNA
matrix has two QSOX1 rows with different measurements: retired Entrez 200058 and
current protein-coding Entrez 5768. `statistics_qc.py` explicitly selects 5768,
records this in `RNA_symbol_resolution.csv`, and rejects unreviewed ambiguous
required symbols instead of choosing the first row. This affects the EMT and
glycolysis signature scores, not the 19 candidate-expression measurements.
Partial rank correlations now rank all variables on the same complete cases.
Binary subtype indicators remain untransformed; this spans the same adjustment
space as ranking their two levels. Undefined partial correlations, including
constant outcomes and numerically zero residuals, return missing estimates.

Expected TCGA table sizes are 570 pathway-association rows, 342 main Cox rows,
57 PAM50-adjusted sensitivity rows, and 69 mutation-prevalence rows including
BRCA1, BRCA2, and TP53 context. Preserve missing values and model status flags.

The corrected cohort has 1,065 CNA-profiled tumours (152 TNBC), 1,059 sequenced
tumours (156 TNBC), and 870 RPPA-profiled tumours (128 TNBC). Adjusted pathway
associations use 1,018 BRCA, 140 TNBC, and 161 basal complete cases. Primary PFI
counts are 1,062/145 events for BRCA, 156/28 for TNBC, and 168/25 for basal.
The BRCA age/stage-adjusted PFI model uses 1,038 patients/136 events; adding PAM50
uses 943/120. The TNBC and basal adjusted Cox models still fail the prespecified
30-event threshold and must remain marked `insufficient_events`.

The initial packaging audit checked archived source and compact-input hashes;
it did not rerun Cox models. The separate 20 October audit reran the complete
original TCGA and mutation/survival scripts: all numeric values in the archived
expression, CNA, pathway, RPPA, main Cox, mutation-prevalence, and PAM50 Cox tables
were reproduced exactly. The corrected scripts were then rerun separately.
No candidate-expression or prognostic-association FDR classification changed;
several borderline pathway, CNA-expression, RPPA, and PH-diagnostic results did.
Use corrected tables together rather than mixing their counts or FDR flags with
the archived report. All 114 available GSE author log2FC/P/FDR values also match
the supplied source table exactly.

The subsequent modular refactor was rerun against those corrected results using
the full source matrices and original purity snapshot. Cohort metadata and all
existing table columns matched exactly except partial-rank floating-point
differences no larger than 1.84e-15; FDR classifications were unchanged. All six
TCGA PNGs were byte-identical, including the separately rerun mutation figure.
The mutation, somatic-variant, and PAM50 sensitivity tables also matched exactly.
The only new main Cox output column is `fit_warnings`, which records fitting
warnings instead of suppressing them. A subsequent zero-residual guard was
checked against all 570 real pathway rows without changing their estimates.

Scientific QC regression checks run without the private source tables:

```bash
python -m unittest discover -s tests -p test_tcga_qc.py -v
```

They check stable-ID resolution regardless of row order, rejection of unknown
duplicate symbols, invariance to observations excluded before ranking, and the
explicit CDR redaction policy. These tests exercise the helpers used by the main
analysis; the full rerun separately verifies integration with the actual inputs.

Run the complete synthetic and regression suite and scoped static checks with:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest
python -m ruff check analysis tests
```

The suite additionally checks import safety, end-to-end output contracts,
complete-case ranks, undefined residual correlations, captured Cox warnings,
clinical flags, and the reviewed QSOX1 row entering the Hallmark scores.

TCGA associations describe patient-tumour context, not olaparib response or
gene-specific drug sensitivity. GSE165914 extraction preserves the authors'
genome-wide differential-expression results; it does not refit DE models from
the supplied fractional processed counts. Continuous 15-micromolar olaparib
exposure and acquired resistance are confounded in that comparison. These
observations do not establish treatment efficacy in the user's edited models.
