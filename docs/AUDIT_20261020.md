# Code and scientific interpretation audit

Baseline: commit `f89fdf41ee65c317a6e0c2e21e833b8d55e2ce2a`.
Audit date: 20 October 2026. All 34 Python files in that snapshot were reviewed.
The original analysis archive and the user's report were not changed.

## What TCGA actually does

TCGA-BRCA is an observational tumour-context analysis of expression, GISTIC
copy-number categories, somatic mutations, Hallmark expression programmes,
RPPA correlations and TCGA-CDR clinical outcomes. It has no olaparib-response
endpoint, treatment-by-gene interaction test, drug-response predictor or synergy
calculation. The cohort was selected for primary tumours, not absence of therapy.
The original clinical annotations include six patients with neoadjuvant treatment.

`build_synthesis.py` and `finalize_priorities.py` contain qualitative literature
curation. `integrate_context.py` adds TCGA/GSE columns; it does not train a model
or compute drug rankings. TCGA must therefore be described as context, not
clinical validation of resistance or a predictor of response.

| PRISM secondary curves pooled across incompatible dose windows | Retain source/screen/batch/dose records; suppress incompatible pooled AUC, R2 and IC50 | 63 compound–cell summaries affected; 28,479 remain numerically unchanged |

The five CDR flags have heterogeneous reasons. Some refer to historical sample
issues with documented replacements; the sample-level matrix does not establish
the replacement aliquot identity. Excluding all five is a declared conservative
QC choice, not proof that all later assays are invalid or that all five patients
withdrew consent.

## Corrected TCGA results

- RNA: 1,077 patients; 156 clinical TNBC, 844 non-TNBC, 77 unclassified;
  170 separately classified PAM50 basal tumours; purity available in 1,019.
- CNA: 1,065 profiled patients, including 152 TNBC. Mutations: 1,059 sequenced,
  including 156 TNBC. RPPA: 870 profiled, including 128 TNBC.
- Nineteen coding candidates are represented; LINC03007 is unavailable.
  LAMTOR2 maps to historical ROBLD3 via Entrez 28956.
- Expression comparisons retain the same FDR classifications: 17/19 candidates
  differ between clinical TNBC and non-TNBC, and 16/19 between basal and other
  assigned PAM50 subtypes. These are subtype contrasts, not resistance contrasts.
- Adjusted TNBC pathway models use 140 complete cases. DERL2–UPR:
  rho 0.273, q=0.00438; NME6–OXPHOS: rho 0.236, q=0.0156.
  LAMTOR2/WDR24–mTORC1 are not significant; CERK–mTORC1 is inverse
  (rho -0.339, q=0.000302). None identifies a KO-created drug dependency.
- PFI: BRCA 1,062 patients/145 events; TNBC 156/28; basal 168/25.
  No candidate meets the PFI FDR threshold in TNBC or basal. Subgroup-adjusted
  models are not fitted because the prespecified event threshold is unmet.
- Across all cohorts, 9 adjusted pathway FDR classifications, 1 CNA–expression
  classification, 2 RPPA classifications and 1 proportional-hazards diagnostic
  cross 0.05. Candidate-expression and prognostic-association FDR classifications
  do not change. Retain these borderline findings as exploratory.

## Limits of this audit

The original GDSC fitting workbooks, Yusoh extraction/OCR intermediates and
historical Reactome GMT were not in the archive. Their retained computations
were checked, but full raw-source re-extraction is not claimed. Supplied MAGeCK
gene summaries are reproducible inputs; these scripts do not rerun MAGeCK from
counts or validate the original normalization, replicate design, CNV correction
or outlier removal. GSE165914's resistant cells remain exposed to olaparib,
confounding acquired resistance with continued treatment.

## Supplied refactor

The separately supplied TCGA refactor improves code organization and testing,
but does not supply a new olaparib-response analysis. Its functions, command-line
input/output options, lazy heavy imports and Cox warning column were adopted
while retaining the scientific audit corrections. The source bundle did not
contain the conservative CDR policy, canonical pathway QSOX1 resolution or drug
and integration fixes. A partial legacy switch is not exposed; historical
reproduction uses the archived code and inputs. See
[the detailed comparison](REFACTOR_REVIEW_20261020.md).

The integrated real-data run reproduced all existing columns of 15 corrected
CSV tables and the cohort-count JSON. Differences were limited to floating-point
rounding in pathway statistics (maximum absolute difference 1.84e-15). All six
TCGA PNGs were byte-identical. Main Cox results retained 228 fitted and 114
insufficient-event rows; the additional warning column was empty in this run.
The numerical-zero-residual safeguard was checked on all 570 real pathway tests
and did not change any estimate or FDR classification. Context integration,
the 21-sheet workbook payload and report-content generation completed using
the integrated outputs.

Run the complete suite with `python -m pytest` after installing
`requirements.txt` and `requirements-dev.txt`. The original 14 audit regressions
also remain runnable with `python -m unittest discover -s tests -v`.
